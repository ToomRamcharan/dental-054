# Ruby Dental Clinic

**Dental Clinic Website** - Generated from UI UX Pro Max Design System

## Design
- **Design Family:** Gradient Modern
- **Color Palette:** Warm Coral
- **Location:** Warangal, Telangana

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Sections
Home, About, Services, Doctors, Technology, Testimonials, Gallery, FAQ, Contact, Google Map, Footer

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
